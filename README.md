# Interactive Resume

The interactive resume of Emile Schoemans. The resume is on the left; click anything highlighted and the work behind it opens in the window on the right.

Plain HTML, CSS and JavaScript: no build step.

- `index.html`: the resume text and the clickable items (`data-k="..."`)
- `app.js`: one panel per item, in the `VIEWS` object
- `style.css`: the design
- `assets/`: photos, screenshots and PDFs

To publish: GitHub repository > Settings > Pages > Deploy from branch `main`, folder `/ (root)`.
